    선형대수 시리즈 2편이다. 1편에서 벡터와 내적을 봤다면, 이번에는 그 벡터들이 사는 공간 전체를 바꾸는 행렬을 다룬다.

    • 1편: 벡터, 기저, 내적
    • 2편: 행렬, 랭크, 행렬식, 역행렬 (이 글)
    • 3편: 고유값과 SVD

    1. 행렬은 함수다

    행렬 A에 벡터 x를 곱하면 새 벡터 Ax가 나온다. 즉 행렬은 “벡터를 넣으면 벡터가 나오는 함수”다. 점 하나만 옮기는 게 아니라 공간 전체를 늘리고, 기울이고, 돌린다.

    A = [2 1; 0 1]은 첫 행이 (2, 1), 둘째 행이 (0, 1)인 2×2 행렬이다. 이 A를 곱하면 회색 정사각형이 초록 평행사변형으로 변한다.

    열만 보면 변환이 다 보인다

    A의 1열은 (2, 0), 2열은 (1, 1)이다. 그림에서 e1=(1,0)은 (2,0)으로, e2=(0,1)은 (1,1)로 갔다.

    행렬의 각 열 = 기저 벡터가 도착하는 위치

    기저만 어디로 가는지 알면 나머지 모든 벡터의 행방도 정해진다. 어떤 벡터든 기저의 조합으로 쓸 수 있으니, 도착한 기저들을 같은 비율로 조합하면 되기 때문이다. 예를 들어 x = (1, 1)이면:

    Ax = 1·(2,0) + 1·(1,1) = (3, 1)

    “x의 좌표만큼 A의 열들을 섞는다”고 보면 된다. 1편의 기저 개념이 여기서 그대로 쓰인다.

    2. 행렬 곱셈 계산법: 내적을 여러 번 하기

    행렬 곱셈은 처음 보면 복잡하지만 핵심은 하나다. 행렬 곱셈 = 내적을 여러 번 하는 것이다.

    행렬 × 벡터

    A의 각 행을 x와 내적하면 결과의 그 칸이 나온다. 그림에서 같은 색끼리 짝을 이룬다.

    [2 1] [1]   [2·1 + 1·1]   [3]
[0 1] [1] = [0·1 + 1·1] = [1]

    앞에서 “열을 섞어서” 구한 (3, 1)과 답이 같다. 두 관점은 같은 계산을 다르게 본 것이다.

    • 계산할 때는 행으로: 행 · 벡터 = 결과 한 칸
    • 의미를 볼 때는 열로: 기저가 어디로 가는지

    행렬 × 행렬

    B의 열 하나하나에 위 계산을 반복하면 된다. 결과의 (i행, j열) 칸은 A의 i행 · B의 j열이다.

    A = [2 1]    B = [1 0]
    [0 1]        [1 1]

AB의 (1,1) = (2,1)·(1,1) = 2+1 = 3
AB의 (1,2) = (2,1)·(0,1) = 0+1 = 1
AB의 (2,1) = (0,1)·(1,1) = 0+1 = 1
AB의 (2,2) = (0,1)·(0,1) = 0+1 = 1

AB = [3 1]
     [1 1]

    행렬곱의 의미는 변환을 이어 붙이기다. BA는 “A로 변형한 다음 B로 변형”이다. 순서를 바꿔 BA를 계산하면 [2 1; 2 2]가 나온다. 그래서 AB ≠ BA다. 옷을 입고 신발을 신는 것과 신발을 신고 옷을 입는 것이 다른 것처럼, 변환도 순서가 중요하다.

    크기 규칙

    (m×n) × (n×p) = (m×p)

    앞 행렬의 열 수와 뒤 행렬의 행 수가 같아야 곱할 수 있다. 행과 열을 내적하려면 두 벡터의 길이가 같아야 하기 때문이다.

    LLM에서 흔히 보는 예: 임베딩 (1×4096) × 가중치 (4096×128) = 결과 (1×128). 4096차원 벡터가 128차원 벡터로 바뀐다.

    예: 90° 회전 행렬

    R = [0 −1; 1 0]에 기저를 넣어 보면:

    R(1,0) = (0·1 + (−1)·0, 1·1 + 0·0) = (0, 1)
R(0,1) = (0·0 + (−1)·1, 1·0 + 0·1) = (−1, 0)

    오른쪽을 가리키던 e1이 위를, 위를 가리키던 e2가 왼쪽을 가리킨다. R은 공간 전체를 반시계 방향으로 90° 회전시키는 행렬이다.

    LLM과의 연결

    신경망의 한 층은 거의 다 “행렬 곱하기 + 비선형 함수”다. Transformer의 가중치 행렬들도 결국 임베딩 공간을 목적에 맞는 다른 공간으로 변형하는 함수다.

    3. 선형독립과 랭크: 변환 후 살아남는 차원

    선형독립

    벡터들 중 어느 하나도 나머지를 섞어서 만들 수 없으면 선형독립이다.

    (1, 2)와 (2, 4)는 (2,4) = 2·(1,2)라서 독립이 아니다. 두 개처럼 보이지만 실제로는 같은 방향 하나뿐이다.

    랭크

    랭크(rank)는 행렬의 열 중 독립인 것의 개수, 다시 말해 변환 후에 살아남는 차원의 수다.

    • 왼쪽 A = [2 1; 0 1]: 두 열 (2,0)과 (1,1)이 서로 다른 방향이다. 평면이 평면으로 간다. 랭크 2
    • 오른쪽 M = [1 2; 2 4]: 두 열 (1,2)와 (2,4)가 같은 방향이다. 평면 전체가 직선 하나(y = 2x)로 찌그러진다. 랭크 1

    여기서 주의할 점은 열의 개수가 아니라 독립인 열의 개수가 랭크라는 것이다. 예를 들어 3×3 행렬의 세 열이 (1,0,0), (0,1,0), (1,1,0)이면 열은 3개지만 랭크는 2다. 세 번째 열이 (1,1,0) = (1,0,0) + (0,1,0)으로 앞의 두 열로 만들어지기 때문이다. 이 행렬은 3차원 공간을 z = 0인 평면(xy평면)으로 찌그러뜨린다.

    찌그러지면 서로 다른 입력이 같은 출력이 된다

    랭크가 줄어든다는 게 실제로 어떤 일인지 M = [1 2; 2 4]에 직접 넣어서 보자.

    M(2, −1):  1행 = 1·2 + 2·(−1) = 0
           2행 = 2·2 + 4·(−1) = 0     →  (0, 0)
M(0, 0)  = (0, 0)

    (2, −1)이라는 0이 아닌 벡터와 원점이 둘 다 (0, 0)으로 간다. 더 와닿는 예도 있다.

    M(1, 0)  = (1·1 + 2·0,  2·1 + 4·0)  = (1, 2)
M(3, −1) = (1·3 − 2,    2·3 − 4)    = (1, 2)

    (1, 0)과 (3, −1)은 전혀 다른 점인데 둘 다 (1, 2)로 간다.

    그러면 누군가 “M을 곱했더니 (1, 2)가 나왔어, 원래 뭐였게?”라고 물었을 때 답할 수 없다. (1, 0)이었을 수도, (3, −1)이었을 수도 있다. 정보가 사라진 것이다.

    왜 이런 일이 생길까? M의 두 열이 같은 방향이라 평면의 모든 점이 직선 y = 2x 위로 눌린다. 2차원이 1차원으로 줄면서 (2, −1) 방향의 정보가 통째로 0이 되는 것이다.

    4. 행렬식: 넓이가 몇 배가 되는가

    찌그러지는지를 숫자 하나로 판별하는 도구가 행렬식(determinant, det)이다.

    [a b; c d]의 det = ad − bc

    det의 의미는 변환 후 넓이가 몇 배가 되는가다.

    • A = [2 1; 0 1]: det = 2·1 − 1·0 = 2. 정사각형(넓이 1)이 넓이 2인 평행사변형이 된다. 위 그림과 일치한다.
    • M = [1 2; 2 4]: det = 1·4 − 2·2 = 0. 넓이가 0, 즉 직선으로 납작해진다.

    det = 0 ⇔ 공간이 찌그러진다 ⇔ 랭크가 꽉 차지 않았다

    5. 역행렬: 변환을 되감는 행렬

    숫자로 먼저

    3을 곱한 걸 되돌리려면 1/3을 곱하면 된다. 3 × 1/3 = 1. 이 1/3이 3의 역수다.

    행렬도 똑같다. A로 변형한 것을 되돌리는 행렬이 역행렬 A⁻¹이다.

    A⁻¹A = I   (I: 단위행렬, 아무것도 하지 않는 변환)

    왕복해 보기

    A   = [2 1; 0 1]
A(1,1)   = (2+1, 0+1)       = (3, 1)    ← 변형
A⁻¹ = [0.5 −0.5; 0 1]
A⁻¹(3,1) = (1.5−0.5, 0+1)   = (1, 1)    ← 원래대로

    직관적인 예로, 90° 회전의 역행렬은 −90° 회전이고, x축 2배 늘리기의 역행렬은 x축 ½배 줄이기다.

    2×2 역행렬 공식

    [a b; c d]⁻¹ = (1/det) · [d −b; −c a]

    대각선은 자리를 바꾸고, 나머지는 부호를 바꾸고, det로 나눈다. A로 확인하면 det = 2이므로:

    A⁻¹ = (1/2) · [1 −1; 0 2] = [0.5 −0.5; 0 1]

    역행렬이 없는 경우

    공식에서 det로 나눈다. det = 0이면 0으로 나눌 수 없으니 역행렬이 없다.

    이것이 앞에서 본 M = [1 2; 2 4]의 상황이다. 평면을 직선으로 찌그러뜨려서 여러 점이 한 점으로 모이니까 되감을 방법이 없다. 숫자 0에 역수가 없는 것과 같은 이치다.

    지금까지의 내용이 하나로 연결된다.

    행렬 열의 방향 랭크 det 역행렬
    A = [2 1; 0 1] 서로 다름 2 2 있음
    M = [1 2; 2 4] 같음 1 0 없음

    LLM과의 연결

    신경망은 정보를 잃지 않도록 이런 찌그러짐을 조심한다. 반대로 LoRA나 attention 헤드처럼 일부러 저차원으로 눌러서 핵심만 남기는 설계도 있다. 둘 다 “되돌릴 수 있는가 = 정보가 보존되는가”라는 같은 관점에서 이해할 수 있다.

    특히 LoRA의 아이디어는 랭크에서 출발한다. LLM의 가중치 행렬은 4096×4096처럼 거대하지만, 파인튜닝할 때 필요한 변화량은 실제로 몇 개의 방향에만 몰려 있다. 그래서 변화량을 랭크가 아주 낮은 행렬로만 학습한다. 이게 정확히 어떻게 가능한지는 3편의 SVD에서 다룬다.

    정리

    • 행렬은 공간을 변형하는 함수이고, 행렬의 열은 기저가 도착하는 곳이다.
    • 행렬 곱셈은 “행 · 열 내적”의 반복이고, 행렬곱은 변환을 이어 붙이는 것이라 순서가 중요하다(AB ≠ BA).
    • 랭크는 독립인 열의 개수, 즉 변환 후 살아남는 차원 수다. 랭크가 줄면 서로 다른 입력이 같은 출력이 되어 정보가 사라진다.
    • 행렬식은 넓이 배율이고, det = 0이면 찌그러진다.
    • 역행렬은 변환을 되감는 행렬이고, det = 0이면 존재하지 않는다.

    다음 글에서는 행렬의 “뼈대 방향”인 고유벡터와, 모든 행렬을 단순한 동작으로 쪼개는 SVD를 다룬다.
