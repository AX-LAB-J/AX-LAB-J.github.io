    • 정리

    선형대수 시리즈의 마지막 3편이다. 행렬의 뼈대를 드러내는 고유값과, 모든 행렬을 단순한 동작으로 쪼개는 SVD(특이값 분해)를 다루고, 이것이 LLM 파인튜닝 기법인 LoRA로 어떻게 이어지는지 본다.

    • 1편: 벡터, 기저, 내적
    • 2편: 행렬, 랭크, 행렬식, 역행렬
    • 3편: 고유값과 SVD (이 글)

    이 글의 예시는 처음부터 끝까지 A = [2 1; 1 2] 하나만 쓴다. 같은 행렬을 여러 각도에서 보면 개념들이 하나로 이어진다.

    1. 고유값과 고유벡터: 방향이 바뀌지 않는 벡터

    행렬을 곱하면 대부분의 벡터는 방향이 틀어진다. 그런데 어떤 특별한 벡터는 방향은 그대로이고 길이만 변한다. 이 벡터가 고유벡터이고, 늘어나는 배율이 고유값 λ(람다)다.

    Av = λv

    A = [2 1; 1 2]에 여러 벡터를 넣어 보면:

    A(1, 1)  = (2+1, 1+2) = (3, 3)  = 3 × (1, 1)     방향 그대로, 3배  → λ = 3
A(1, −1) = (2−1, 1−2) = (1, −1) = 1 × (1, −1)    방향 그대로, 1배  → λ = 1
A(1, 0)  = (2, 1)                                방향이 틀어짐 → 고유벡터 아님

    왜 중요한가: 행렬의 뼈대 방향

    A는 겉으로 보면 섞고 비트는 복잡한 변환이다. 그런데 고유벡터 방향으로 보면 “(1,1) 방향으로 3배, (1,−1) 방향으로 1배”가 전부다. 고유벡터를 기저로 쓰면 행렬이 그냥 늘리기만 하는 단순한 변환이 된다. 1편의 기저 변환이 여기서 다시 등장한다.

    고유값 찾는 법

    대각행렬이면 바로 보인다. A = [3 0; 0 2]에 기저를 넣으면:

    A(1,0) = (3·1 + 0·0, 0·1 + 2·0) = (3, 0) = 3·(1,0)   → λ = 3
A(0,1) = (3·0 + 0·1, 0·0 + 2·1) = (0, 2) = 2·(0,1)   → λ = 2

    x축으로 3배, y축으로 2배 늘리기만 하는 행렬이니 대각선 숫자가 곧 고유값이다.

    대각행렬이 아니면 다음 순서로 푼다.

    Av = λv를 옮기면 (A − λI)v = 0이다. 0이 아닌 v가 0으로 가려면 (A − λI)가 공간을 찌그러뜨려야 한다. 2편에서 본 것처럼 찌그러짐의 판별은 행렬식이다. 따라서:

    고유값: det(A − λI) = 0을 푼다 → 고유벡터: 그 λ를 넣고 (A − λI)v = 0을 푼다

    A = [2 1; 1 2]에 적용하면:

    1단계. 고유값
A − λI = [2−λ  1 ; 1  2−λ]
det = (2−λ)(2−λ) − 1·1 = 0
(2−λ)² = 1  →  2−λ = ±1  →  λ = 1 또는 3

2단계. λ = 3일 때 고유벡터
(A − 3I)v = [−1  1; 1  −1][x; y] = [0; 0]
→ −x + y = 0  →  x = y  →  v = (1, 1)

    λ = 1도 같은 방식으로 풀면 x = −y, 즉 (1, −1)이 나온다. 그림의 초록·파랑 벡터와 같다.

    랭크와의 연결

    고유값이 0이면 그 방향은 0배, 즉 납작해진다. 2편의 M = [1 2; 2 4]는 (2, −1) 방향의 고유값이 0이다. M(2,−1) = (0,0)이었던 것, 그래서 역행렬이 없었던 것이 바로 이 때문이다.

    LLM과의 연결

    고유값이 큰 방향은 데이터나 변환에서 가장 중요한 방향이다. 임베딩을 2D로 시각화할 때 쓰는 PCA가 이 원리를 쓴다. 그리고 이 아이디어를 모든 행렬로 넓힌 것이 다음의 SVD다.

    2. SVD: 어떤 행렬이든 세 동작으로 쪼갠다

    SVD가 던지는 질문은 이것이다.

    “이 복잡한 변환을 아주 단순한 동작들로 쪼갤 수 없을까?”

    답은 어떤 행렬이든 다음처럼 쪼갤 수 있다는 것이다.

    A = U Σ Vᵀ

    그림처럼 원(모든 방향의 길이 1짜리 벡터)에 행렬을 곱하면 타원이 된다. SVD는 이 과정을 세 단계로 나눠 보여준다.

    2-1. 좋은 축

    A = [2 1; 1 2]에서 (1,1)과 (1,−1)은 A가 비틀지 않고 늘리기만 하는 방향이었다. 보통 축 (1,0)으로 보면 A는 “늘리면서 비틀기”라 복잡하지만, 이 대각선 축으로 보면 “한쪽 3배, 다른 쪽 1배”로 단순해진다. 그래서 좋은 축이다.

    일반 행렬에서 좋은 축은 서로 직각인 입력 축들이, 변환 후에도 서로 직각인 출력 축으로 가는 방향이다. A처럼 대칭인 행렬은 입력 축과 출력 축이 같아서 고유벡터와 일치하지만, 일반 행렬에서는 입력의 좋은 축과 출력의 좋은 축이 다르다. 고유값 분해는 정사각행렬 중에서도 일부에만 가능하지만, SVD는 4096×128 같은 직사각형 행렬에서도 항상 이런 축을 찾아준다. 그래서 실전에서 훨씬 많이 쓰인다.

    2-2. 특이값: 각 축에서 늘리는 배율

    좋은 축마다 늘리는 배율이 있다. 이것이 특이값(singular value)이다. 큰 것부터 σ₁ ≥ σ₂ ≥ … 순서로 쓰고, 항상 0 이상이다. A의 특이값은 σ₁ = 3, σ₂ = 1이다. 그림에서 타원의 긴 축 길이가 σ₁, 짧은 축 길이가 σ₂다.

    특이값의 본질적인 의미는 각 방향의 중요도다. 3배로 늘어나는 방향은 결과를 크게 좌우하고, 만약 0.01배인 방향이 있다면 그 방향은 결과에 거의 영향을 주지 않는다. 특이값은 “이 방향이 얼마나 중요한가”의 점수다.

    2-3. U, Σ, Vᵀ: 쪼개고, 늘리고, 합치기

    세 행렬로 나누는 이유는 복잡한 변환을 이해할 수 있는 단순한 동작 세 개로 보기 위해서다. A에 (1, 0)을 곱하는 과정을 좋은 축의 관점에서 다시 해 보자.

    ① 성분 뽑기 (Vᵀ의 역할)

    입력 (1, 0)을 좋은 축 방향의 조각들로 나눈다. 1편에서 v = (3, 2)를 다른 기저로 재서 (2.5, −0.5)를 얻었던 것과 똑같은 일이다.

    (1, 0) = 0.5·(1, 1) + 0.5·(1, −1)

    확인: 0.5·(1,1) + 0.5·(1,−1) = (0.5+0.5, 0.5−0.5) = (1, 0) ✓

    즉 “(1,1) 방향으로 0.5만큼, (1,−1) 방향으로 0.5만큼”이다. 각 축 방향과 얼마나 겹치는지 재는 것이므로 계산은 내적으로 한다. 이 숫자들을 구하는 것이 Vᵀ의 역할이다.

    ② 늘리기 (Σ의 역할)

    각 조각을 그 축의 특이값만큼 늘린다.

    (1, 1) 쪽:   0.5 × 3 = 1.5
(1, −1) 쪽:  0.5 × 1 = 0.5

    ③ 다시 합치기 (U의 역할)

    늘린 조각들을 출력 공간의 방향으로 다시 배치해서 하나로 합친다.

    1.5·(1, 1) + 0.5·(1, −1) = (1.5+0.5, 1.5−0.5) = (2, 1)

    A(1,0)을 직접 계산한 값 (2·1 + 1·0, 1·1 + 2·0) = (2, 1)과 똑같다 ✓

    그래서 A = U Σ Vᵀ는 “쪼개고(Vᵀ) → 늘리고(Σ) → 합친다(U)”를 식으로 쓴 것이다.

    • Vᵀ와 U는 방향만 바꾸고 길이는 바꾸지 않는다(회전 또는 뒤집기).
    • 실제 크기 변화는 전부 Σ에 있다. 행렬의 핵심 정보가 특이값에 모인다는 뜻이다.

    A는 대칭행렬이라 U와 V가 같지만, 일반 행렬은 입력의 좋은 축(V)과 출력의 좋은 축(U)이 달라서 둘을 따로 쓴다.

    3. 랭크 1 조각들의 합

    위 과정을 다시 보면 A는 사실 서로 독립된 두 작업을 합친 것이다.

    • 작업 1: (1,1) 성분을 뽑아 3배 해서 (1,1) 방향으로 내보내기
    • 작업 2: (1,−1) 성분을 뽑아 1배 해서 (1,−1) 방향으로 내보내기

    각 작업을 행렬로 쓰면 다음과 같다.

    작업 1 = 3 × [0.5  0.5; 0.5  0.5]  = [1.5  1.5; 1.5  1.5]
작업 2 = 1 × [0.5 −0.5; −0.5 0.5]  = [0.5 −0.5; −0.5 0.5]
합                                  = [2 1; 1 2] = A ✓

    각 작업 행렬은 결과를 한 방향으로만 내보낸다. 모든 행이 같은 모양(비율)이고, 출력이 직선 하나뿐이니 랭크 1이다. 그래서 “A는 랭크 1 조각들의 합”이고, 각 조각 앞의 숫자(3, 1)가 특이값, 즉 그 조각의 무게다.

    이것을 기호로 쓴 것이 다음 공식이다.

    A = σ₁u₁v₁ᵀ + σ₂u₂v₂ᵀ + σ₃u₃v₃ᵀ + …
    • vᵢ: 어느 방향의 성분을 뽑을지 (입력의 좋은 축)
    • σᵢ: 몇 배 할지 (특이값, 조각의 무게)
    • uᵢ: 어느 방향으로 내보낼지 (출력의 좋은 축)

    uᵢvᵢᵀ는 “세로벡터 × 가로벡터”로 만든 행렬이라 항상 랭크 1이다. 예를 들어 u₁ = v₁ = (1,1)/√2이면 u₁v₁ᵀ = [0.5 0.5; 0.5 0.5]로, 위의 작업 1 행렬과 같다.

    4. 저랭크 근사: 무거운 조각만 남기기

    조각마다 무게가 다르니 가벼운 조각을 버려도 결과는 크게 변하지 않는다.

    A에서 무게 1짜리 조각을 버리고 무게 3짜리만 남기면:

    A ≈ [1.5 1.5; 1.5 1.5]     (원래 A = [2 1; 1 2])

    꽤 비슷하다. 조각 하나만 남겼으니 랭크 1 근사다. 일반적으로 특이값이 큰 앞쪽 r개 조각만 남기는 것을 랭크 r 근사(저랭크 근사)라고 한다. 앞의 SVD 그림으로 보면, σ₂가 아주 작을 때 타원이 거의 선이 되는 것과 같다. 짧은 축을 무시해도 모양이 크게 달라지지 않는다.

    왜 하는가: 큰 행렬에서의 이득

    2×2에서는 이득이 작지만, 큰 행렬에서는 엄청나다.

    4096×4096 행렬           = 숫자 약 1,680만 개
조각 하나 = u(4096) + v(4096) + σ(1) ≈ 8,200개
8조각                     ≈ 6.5만 개

    특이값이 앞의 8개만 크고 나머지가 거의 0이라면, 8조각만 저장해도 거의 같은 행렬이다. 메모리와 계산을 약 256분의 1로 줄이면서 핵심 정보는 지킬 수 있다. 사진 압축도 같은 원리다. 사진을 행렬로 보고 특이값 상위 몇십 개만 남겨도 알아볼 만한 사진이 된다.

    즉 저랭크 근사를 하는 이유는 메모리와 계산을 크게 줄이면서 중요한 정보는 지키기 위해서다.

    5. LoRA: 변화량은 원래 몇 조각이면 충분하다

    LLM 파인튜닝은 가중치 행렬 W를 W + ΔW로 바꾸는 것이다. W가 4096×4096이면 ΔW도 약 1,680만 개의 숫자다. 이런 행렬이 모델 안에 수백 개 있으니 전부 학습하려면 비용이 매우 크다.

    LoRA(Hu et al., 2021)는 파인튜닝으로 생기는 변화량 ΔW는 본질적으로 랭크가 낮다, 즉 특이값이 앞의 몇 개만 크고 나머지는 거의 0이라고 보고, 처음부터 ΔW를 저랭크 형태로만 학습한다.

    ΔW = B · A
B: 4096 × 8,   A: 8 × 4096   →  ΔW의 랭크는 최대 8

학습할 숫자: 4096·8 + 8·4096 ≈ 6.5만 개   (원래 약 1,680만 개)

    2편의 크기 규칙으로 보면 (4096×8) × (8×4096) = (4096×4096)이라 원래 가중치와 같은 크기가 나온다. 하지만 중간에 8차원을 거치므로 랭크는 최대 8이다. 학습할 숫자는 약 256분의 1로 줄어들고, 성능은 전체 파인튜닝과 거의 비슷하다.

    결국 LoRA는 “r개의 랭크 1 조각만으로 변화량을 표현한다“는, 이 글에서 본 저랭크 근사의 아이디어를 학습 단계에 그대로 적용한 것이다.

    정리

    • 고유벡터는 행렬을 곱해도 방향이 바뀌지 않는 벡터이고, 고유값은 그 방향의 배율이다. det(A − λI) = 0으로 구한다.
    • SVD는 어떤 행렬이든 “좋은 축으로 쪼개고(Vᵀ) → 축마다 특이값만큼 늘리고(Σ) → 합친다(U)”로 분해한다.
    • 특이값은 각 방향의 중요도이며, 행렬의 실제 크기 변화는 모두 특이값에 담긴다.
    • 행렬은 랭크 1 조각들의 합 σ₁u₁v₁ᵀ + σ₂u₂v₂ᵀ + …이고, 특이값이 작은 조각을 버리면 저랭크 근사가 된다.
    • LoRA는 파인튜닝 변화량을 처음부터 저랭크 행렬로만 학습해서, 학습할 숫자를 수백 분의 1로 줄인다.

    이것으로 선형대수 단원을 마친다. 행렬미분은 역전파와 함께 미적분·최적화 단원에서 다루고, 다음 단원은 언어모델의 손실함수를 이해하기 위한 확률과 정보이론이다.

    5 분 소요

    행렬의 열은 기저가 도착하는 곳이다. 공간을 찌그러뜨리는 행렬은 정보를 잃고, 그래서 되돌릴 수 없다.

    1. 벡터, 기저, 내적

    3 분 소요

    같은 벡터도 어떤 자(기저)로 재느냐에 따라 숫자가 달라진다. 내적은 두 벡터가 얼마나 같은 쪽을 보는지 알려준다.
